# Small Sharp Tools

Source for [smallsharptools.com](https://www.smallsharptools.com/) — a single static page showcasing Mac apps, web tools and games by Brennan Stehling.

## Structure

- `index.html` — the entire site (inline CSS, no build step)
- `images/` — app icons and screenshots

## Local preview

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
